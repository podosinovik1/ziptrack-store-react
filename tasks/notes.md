# Заметки
1)  Придумать элемент Каталог (`Catalog`)
    На верхнем уровне в этот элемент будем передавать JSON объект, 
    который через пропсы будет парситься в элементы каталога.

    БД в теории нам не нужна, и может подойдет какая-нибудь гугл таблица, из которой можно подтягивать инфу.

    Фильтры:
    - можно добавить `check-button`, в  качестве значений передаем свойства `catalogFlat`-json
    - фильтр принимает объект и атрибуты по которым проводится филььтрация
    - пользователь прожимает `check-button`, собираем все выбранные свойства, передаем в фильтр в качетстве
    атрибутов для фильтрации
